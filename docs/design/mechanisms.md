# **TrackStacker Mechanisms**

TrackStacker utilizes magnets not only to connect Tracks to the Play Surface and to each other, but also as fundamental building blocks for achieving mechanisms normally only possible with the use of springs and detents


## **The Magnetic Spring**

The property of magnets of like polarity to repel each other can be utilized to create a consistent spring force, if the parts housing the repelling magnets are constrained mechanically. The number of magnets and the distance between them can be used to precisely control the effective amount of spring force.
